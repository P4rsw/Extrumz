## وضعیتِ ماجرا

موسیقی‌ات از قبل در تلگرام هست. در کانال‌ها، در پیام‌های ذخیره‌شده، در گروهی که
سال‌ها پیش یک دوست برایت فرستاد. مالِ خودت است، همین حالا هم هست، و هیچ راهی
نیست که پخشش کنی.

اکسترامز یک پخش‌کننده برای همان است. صدای چت‌ها و کانال‌هایی را که به آن اشاره
می‌کنی ایندکس می‌کند و به تو می‌دهد: صفِ پخش، پلی‌لیست، لایک، تاریخچه، جست‌وجو،
لیریکس، کاورِ آلبوم، و صفحهٔ پخشی که ارزشِ باز ماندن دارد.

هیچ‌چیز جایی آپلود نمی‌شود. هیچ‌چیز کپی نمی‌شود. فایل‌ها تکان نمی‌خورند — فقط
بالاخره پخش می‌شوند.

## چه کار می‌کند

| | |
|---|---|
| **📥 ایندکس می‌کند** | چت‌ها و کانال‌ها را برای صدا می‌گردد، با پیشرفتی که می‌شود تماشا کرد، قابلِ ازسرگیری، و با سقفِ زمان برای هر صفحه — تا یک چتِ کند، بقیه را متوقف نکند |
| **▶️ پخش می‌کند** | در پس‌زمینه، روی یک media session واقعی، بدونِ گله و با crossfade |
| **📚 مرتب می‌کند** | پلی‌لیست، لایک، تاریخچه، جست‌وجو در هر چیزی که ایندکس شده، و شش نوع مرتب‌سازی |
| **🎤 لیریکس** | هم‌زمان با کلمه، از چند منبع، با امکان انتخاب دستی وقتی انتخابِ خودکار اشتباه می‌افتد |
| **🎨 کاور** | اول تامبنیل‌های خودِ تلگرام، بعد پایگاه‌های بیرونی، و رنگِ صفحهٔ پخش از روی همان کاور |
| **🌍 فارسی** | چیدمانِ راست‌به‌چپِ واقعی، نه یک آینه‌ی سطحی. انگلیسی هم هست. |
| **🛡 پروکسی** | یک صفحه، نه یک تنظیمِ پنهان — پایین‌تر توضیح داده‌ام |
| **🎧 فایل‌های محلی** | موسیقیِ خودت، کنارِ کتابخانهٔ تلگرام |

## بخشی که مهم است

**اگر تلگرام از آنجایی که هستی در دسترس نباشد، هیچ‌کدام از بالا کار نمی‌کند.**

برای همین پروکسی یک تنظیمِ پنهان در سه منوی تو‌درتو نیست. یک صفحه است، روی همان
صفحهٔ ورود کنارِ دکمه‌های ورود پیشنهاد می‌شود، و درست مثل یک پروکسی رفتار می‌کند:

- **MTProto، SOCKS5 و HTTP.**
- **یک لیست، نه یک فیلد.** پروکسی‌ها نگه داشته می‌شوند، اسم می‌گیرند و عوض می‌شوند.
  اضافه کردنِ دومی، اولی را پاک نمی‌کند.
- **قبل از اعتماد، تست می‌شود.** پروکسی مستقیماً در برابرِ خودِ تلگرام — روی همان
  دیتاسنتری که حسابِ تو روی آن کار می‌کند — سنجیده می‌شود و نتیجه‌اش کنارِ
  اتصالِ مستقیم می‌نشیند. یعنی «این کمک می‌کند؟» جواب دارد، نه حدس.
- **یک سپر روی صفحهٔ اصلی** وقتی پروکسی روشن است، چون پروکسیِ روشنِ فراموش‌شده
  دقیقاً همان چیزی است که آدم را گیر می‌اندازد.

> **حدّ صادقانه:** MTProto پروتکلِ خودِ تلگرام است، پس فقط تلگرام را می‌برد — نشست،
> چت، صدا و تامبنیل. کاورِ آلبوم که از Deezer یا iTunes گرفته می‌شود و لیریکسی که
> با HTTP می‌آید، از مسیرِ معمولی می‌روند و در تونل نیستند. اگر این‌ها برایت مهم
>‌اند، یک VPNِ سراسری هم کنارش بگذار.

## بسازیدش

```bash
git clone https://github.com/P4rsw/Extrumz.git
cd Extrumz
JAVA_HOME=/usr/lib/jvm/java-21-temurin ./gradlew :app:assembleProdDebug
```

**اول `api_id` و `api_hash` خودت را از تلگرام بگیر.** تلگرام از هر اپ
می‌خواهد با اعتبارنامه‌ای خودش را معرفی کند — یعنی ثبت‌شده به نامِ **همان** اپ.
استفاده از اعتبارنامهٔ کسِ دیگر — از جمله آنهای معروفی که در هزاران فورک و هزاران
آموزش هست — باعث محدود شدنِ نرخ و در نهایت بسته شدنِ اپ می‌شود؛ و آن‌که این را
می‌کشد، **کاربر** است، نه توسعه‌دهنده.

۱. به [my.telegram.org](https://my.telegram.org) برو و با شمارهٔ تلگرامت وارد شو
۲. **API development tools** → یک اپ بساز (هر اسمی، پلتفرم *Android*)
۳. دو مقدار را در `local.properties` بگذار:

```properties
TG_API_ID=1234567
TG_API_HASH=0123456789abcdef0123456789abcdef
```

`local.properties` در gitignore است. همین‌طور بماند.

**تست‌ها:** `./gradlew :app:testProdDebugUnitTest`
**نسخهٔ امضاشده:** یک‌بار `./tools/make-keystore.sh` و بعد `./release.sh`

## ساختارِ پروژه

```
app/        خودِ اپ اندروید — Kotlin، Compose، Room، TDLib
backend/    بک‌اندِ لیریکس که LyricsPlus از آن می‌پرسد، به زبانِ Go
native/     تحلیلِ صدا که ترنزیشن‌های بیت‌مچ رویش کار می‌کنند، به زبانِ C++
tools/      ساختنِ keystore و اسکریپتِ آماده‌سازیِ انتشار
```

تک‌ماژول، Material 3، تمام‌صفحه. در buildهای release، `R8` اجرا می‌شود و هر
کتابخانه‌ای که کلاسش را **با اسم** پیدا می‌کند — JNIِ TDLib، JNIِ ONNX،
protobuf-lite — کامل نگه داشته می‌شود در `proguard-rules.pro`.

**یک چیز که خوب است بدانی:** نسخهٔ release با نسخهٔ debug فرق دارد. `R8` فقط در
release اجرا می‌شود و می‌تواند چیزی را حذف کند که در debug هرگز حذف نمی‌شد. دو
بار یک خرابیِ مخصوصِ release از این مخزن بیرون آمد — و نه با تست، چون تست‌ها
`R8` را اجرا نمی‌کنند، بلکه با **نصب کردنِ APKِ release روی گوشی و استفاده کردن از
آن**. اگر این را fork کردی، آن گام را انجام بده.

## آنچه تمام نیست

هر روز استفاده می‌شود و کار می‌کند، ولی اوایلِ کار است؛ و صادق بودن بهتر از آن
است که خواننده خودش پیدایش کند:

- ترنزیشن‌های بیت‌مچ و جدا کردنِ صدای خواننده از پروژهٔ اصلی به‌جامانده‌اند و
  وزنِ زیادی در APK دارند.
- کاور و لیریکس از پروکسیِ MTProto رد نمی‌شوند.
- ترجمه فقط فارسی و انگلیسی است، و فارسی آن است که رسیدگی می‌شود.
