# Maintainers

This document lists the maintainers responsible for Extrumz.

| Maintainer | GitHub | Responsibilities |
|---|---|---|
| Parsa | [@P4rsw](https://github.com/P4rsw) | Fork maintainer: the Telegram layer, the proxy, the library scanner, RTL, releases |
| Kushagra Singh | [@kushagrasinghx](https://github.com/kushagrasinghx) | Original project (BitChord): creator, core architecture, release management, PR reviews |

Extrumz is a fork of BitChord. The list above names both: the people who
maintain this fork, and the person whose work it is built on. Keeping the
second name here is not a courtesy -- the GPL asks for it, and removing it
would take credit for someone else's architecture.

## Responsibilities

Maintainers oversee project direction, repository maintenance, review and merging of contributions, and release management.
